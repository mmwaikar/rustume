# rustume

Rust-based resume visualizer built with Leptos.

## Current scope

- Separate GitHub repository
- Leptos client-side app
- Spectrum 2-style UI shell
- Rust-native data shaping for resume analytics and Cytoscape payloads
- GitHub Pages deployment
